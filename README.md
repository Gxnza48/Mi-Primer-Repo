# 🚀 Mi-Primer-Repo

> Mi primer repo de git, anashe ✨

Bienvenido/a a mi primer repositorio. Acá arranca todo: un proyecto en Python ordenadito, con su estructura bien armada y listo para crecer.

## 📁 Estructura

```
Mi-Primer-Repo/
├── data/             # Datos de entrada y salida
├── src/              # Código fuente
├── tests/            # Tests
├── .gitignore        # Lo que Git ignora
├── requirements.txt  # Dependencias
└── README.md         # Estás acá 👋
```

## ⚙️ Cómo arrancar

1. Cloná el repo:
   ```bash
   git clone https://github.com/Gxnza48/Mi-Primer-Repo.git
   cd Mi-Primer-Repo
   ```
2. Creá y activá un entorno virtual:
   ```bash
   python -m venv .venv
   source .venv/bin/activate   # En Windows: .venv\Scripts\activate
   ```
3. Instalá las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
4. Corré los tests:
   ```bash
   pytest
   ```
